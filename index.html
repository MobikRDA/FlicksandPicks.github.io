Clipper

Личный инструмент: нарезает длинные видео владельца на короткие вертикальные ролики.

Что он делает

Программа работает на домашнем компьютере владельца. Она берёт его длинные видео — записи разговоров, интервью, шоу, — распознаёт речь, находит самодостаточные фрагменты, кадрирует их в вертикальный формат 9:16, добавляет субтитры и выравнивает громкость.

Как используется TikTok

  1. Владелец один раз входит в свой аккаунт TikTok через официальный механизм авторизации.
  2. Программа запрашивает единственное разрешение — video.upload.
  3. Готовый ролик отправляется в черновики владельца через Content Posting API.
  4. Публикацию владелец завершает сам, вручную, в приложении TikTok.

Программа ничего не публикует самостоятельно, не читает чужой контент и не работает с аккаунтами других людей.

Кто пользуется

Только владелец программы, со своим собственным аккаунтом. Это не сервис и не продукт для сторонних пользователей: регистрации нет, аккаунтов нет, сервера нет.
